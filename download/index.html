Verify · install · update

  1. Mac — download the DMG, then check it: shasum -a 256 <file>.dmg must equal the sha256 shown. Open, drag the app into place. The in-app updater (/update) re-checks the same signed feed and verifies ed25519 + size + SHA-256 before it offers “Restart to update”.
  2. iOS / iPadOS — there is no public IPA yet (free Apple profile). Lab builds are signed on the Mac and installed by USB or Wi-Fi pairing with xcrun devicectl device install app. The apps' NOTIFICATIONS tile alerts you over any IP route (Wi-Fi, mobile data, hotspot, USB-network, DSL). iOS can't take an app update over Bluetooth, AirDrop or non-IP USB, and an app can't replace itself.
  3. Feeds — mirrors: rizal.info · rizal.pw · GitHub raw. A Mac relay on your own network can serve the same feeds + eggs to the apps when the internet is out of reach.
